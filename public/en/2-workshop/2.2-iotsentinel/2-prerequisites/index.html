Prerequisites

Python Environment Setup

To run the truck simulator source code, your computer needs Python and the AWS IoT connection library installed.

  1. Check the Python version on your computer by opening Terminal/Command Prompt and typing: python --version (Requires version 3.9 or higher).

  1. Python Installation (If not already installed):

    • For Windows: Go to python.org/downloads and download the latest installer.

      Important Note: On the first installation screen, you MUST check the box “Add Python.exe to PATH” before clicking Install Now. This allows the Terminal to recognize the python command.

    • For macOS (Using Homebrew): 
      brew install python
    • For Linux (Ubuntu/Debian): 
      sudo apt update && sudo apt install python3 python3-pip -y

  2. Install the AWSIoTPythonSDK library. This is the most crucial library for MQTT communication. Run the command:

    pip install AWSIoTPythonSDK

Create Simulator Source File

We will create a Python file that acts as the smart sensor on the trucks. This file is responsible for simulating the journey data of 10 trucks and sending it to the AWS Cloud via the MQTT protocol.

  1. Open VS Code.
  2. Create a new file named truck_simulator.py.
  3. Copy and paste the code below into the file:
import time
import json
import random
from AWSIoTPythonSDK.MQTTLib import AWSIoTMQTTClient

# ==========================================
#  CONFIGURATION PARAMETERS (TO BE UPDATED IN CHAPTER 2)
# ==========================================
# This endpoint will be obtained from AWS IoT Core Settings
IOT_ENDPOINT = "YOUR_AWS_IOT_ENDPOINT" 

# Paths to security certificates
PATH_TO_ROOT_CA = "certs/AmazonRootCA1.pem"
PATH_TO_CERT = "certs/your-certificate.pem.crt"
PATH_TO_PRIVATE_KEY = "certs/your-private.pem.key"

CLIENT_ID = "Vaccine_Fleet_Simulator"
TOPIC = "telemetry/trucks"

# Create a simulated list of 10 trucks with starting coordinates
TRUCKS = [{"id": f"T-{100+i}", "lat": 10.7626 + (i * 0.01), "lon": 106.6602 - (i * 0.01)} for i in range(10)]

# ==========================================
# INITIALIZE SECURE MQTT CONNECTION
# ==========================================
myMQTTClient = AWSIoTMQTTClient(CLIENT_ID)
myMQTTClient.configureEndpoint(IOT_ENDPOINT, 8883)
myMQTTClient.configureCredentials(PATH_TO_ROOT_CA, PATH_TO_PRIVATE_KEY, PATH_TO_CERT)

print(f"Connecting to AWS IoT Core...")

# ==========================================
# DATA SEND LOOP (1 SECOND/TIME)
# ==========================================
try:
    myMQTTClient.connect()
    print(" Connection successful!\n")
    while True:
        for truck in TRUCKS:
            # Generate random data for temperature and coordinates
            data = {
                "truck_id": truck["id"],
                "temperature": round(random.uniform(2.0, 8.0), 2),
                "latitude": round(truck["lat"] + random.uniform(-0.001, 0.001), 6),
                "longitude": round(truck["lon"] + random.uniform(-0.001, 0.001), 6),
                "timestamp_ms": int(time.time() * 1000)
            }
            
            payload = json.dumps(data)
            myMQTTClient.publish(TOPIC, payload, 1)
            print(f"[{truck['id']}] Sent: {payload}")
            
        time.sleep(1) 

except KeyboardInterrupt:
    print("\n Stopped sending data.")
    myMQTTClient.disconnect()

  1. Save the file in your project directory.

Note: You need to replace YOUR_AWS_IOT_ENDPOINT and the certificate filenames with the actual information you will initialize in the next System Deployment section.

Preparation Steps

To build a real-time truck monitoring system, we need to prepare a simulated “data source” and set up the programming environment on a personal computer. Since there are no real hardware devices, we will use Python to simulate 10 smart trucks.

  • Python & AWSIoTPythonSDK: This is the main tool suite to turn your computer into an IoT Edge device. This library helps establish a secure connection via the MQTT protocol to the AWS Cloud, encrypts data, and sends temperature information to the system.

  • AWS Region (Singapore - ap-southeast-1): To optimize speed and cost, we will deploy all resources in the Singapore region. Selecting the correct Region from the start allows services like SQS, Lambda, and DynamoDB to link with each other automatically and securely.

Thoroughly preparing the simulated environment is an important step to ensure the data stream can flow smoothly into the Pipeline in the next steps.
