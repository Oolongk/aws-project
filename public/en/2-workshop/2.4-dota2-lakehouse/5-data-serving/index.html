Upgrade the PySpark source code of the AWS Glue Job. In addition to saving the Parquet file to S3, Glue will directly calculate the win rate (Winrate) and pick rate (Pickrate), and use the boto3 library to ingest the results directly into DynamoDB.

Step Action Technical Details
1 Open Glue Studio Go to AWS Console > Search for AWS Glue > ETL Jobs > Select Visual ETL or directly open the source code of the dota2_etl_job Job created in section 2.3.
2 Update Script Select the Script tab, delete all the old source code, and replace it with the upgraded PySpark code below.
3 Configure Parameters Ensure that the RAW_PATH, PROCESSED_PATH variables, and the DynamoDB table name match your system settings.
4 Save and Run Click Save > Click Run to trigger the aggregation pipeline.
5 Verify Results Access DynamoDB Console > Tables > Click the dota2_hero_metrics table > Click the Explore table items button to check if the Hero metrics records have been successfully loaded.

Upgraded PySpark source code (dota2_etl_job_v2.py):

import sys
import boto3
from pyspark.context import SparkContext
from awsglue.context import GlueContext
from pyspark.sql.functions import explode, col, from_unixtime, to_date, count, sum as _sum, when, lit

sc = SparkContext.getOrCreate()
glueContext = GlueContext(sc)
spark = glueContext.spark_session

RAW_PATH = "s3://dota2-raw-zone-yourname/raw_matches/"
PROCESSED_PATH = "s3://dota2-processed-zone-yourname/matches_parquet/"
DYNAMODB_TABLE = "dota2_hero_metrics"

# 1. Read raw data and Flattening
df = spark.read.json(RAW_PATH)
df_exploded = df.select(
    col("match_id"),
    to_date(from_unixtime(col("start_time"))).alias("match_date"),
    explode(col("players")).alias("player")
)
df_final = df_exploded.select(
    "match_id",
    "match_date",
    col("player.hero_id").alias("hero_id"),
    col("player.win").alias("is_win")
)

# [Chapter 2 Optimization]: Write clean long-term historical data as Parquet Snappy to S3
df_final.write.mode("append").partitionBy("match_date").parquet(PROCESSED_PATH, compression="snappy")

# 2. [Chapter 4 Upgrade]: Calculate Aggregation Metrics using Spark DataFrame API
print("Calculating aggregated Winrate and Pickrate for Heroes...")
total_matches = df.count()

df_metrics = df_final.groupBy("hero_id").agg(
    count("match_id").alias("total_picks"),
    _sum(when(col("is_win") == True, 1).otherwise(0)).alias("total_wins")
)

# Calculate data percentages
df_metrics = df_metrics.withColumn("win_rate", (col("total_wins") / col("total_picks")) * 100) \
                       .withColumn("pick_rate", (col("total_picks") / lit(total_matches)) * 100)

# 3. Load data into DynamoDB using boto3 within Spark's distributed partitions
def upload_row_to_dynamodb(row):
    # Initialize boto3 client inside each Spark Cluster Worker Node
    dynamodb = boto3.resource('dynamodb', region_name='ap-southeast-1')
    table = dynamodb.Table(DYNAMODB_TABLE)
    
    # Perform Upsert action (Write new or update if hero_id exists)
    table.put_item(
        Item={
            'hero_id': int(row['hero_id']),
            'total_picks': int(row['total_picks']),
            'total_wins': int(row['total_wins']),
            'win_rate': str(round(row['win_rate'], 2)), # Cast to string to prevent Float format errors in DynamoDB
            'pick_rate': str(round(row['pick_rate'], 2))
        }
    )

# Execute distributed function across all rows of the DataFrame
print("Starting distributed data load into Amazon DynamoDB...")
df_metrics.rdd.foreach(upload_row_to_dynamodb)
print("Data load completed!")

No matter how useful the analyzed data is, it loses value if the system takes several minutes to display it to the user.

In this chapter, you will build the Speed Layer for the system using the NoSQL database Amazon DynamoDB. After processing the clean data, AWS Glue PySpark will directly pre-calculate the Meta metrics (Aggregated Metrics) and load them into DynamoDB, ensuring that the Frontend application can retrieve information with a latency of less than 100ms.

You will build a Lambda function that acts as the API Backend. It will receive the hero_id parameter sent from the browser, query DynamoDB, and return the JSON result.

Step Action Technical Details

3 Basic Configuration Select Author from scratch. Function name: dota2-backend-api. Runtime: Select Python 3.9 (or newer).

5 Attach DynamoDB Read Permission Go to the Configuration tab > Permissions > Select the blue Role name link. The system will open the IAM console in a new tab.

Python source code for Lambda:

import json
import boto3

DYNAMODB_TABLE = "dota2_hero_metrics"

def lambda_handler(event, context):
    print("Received event:", json.dumps(event))
    
    # 1. Extract hero_id parameter from API Gateway path (Query String or Path Parameter)
    query_params = event.get('queryStringParameters') or {}
    hero_id = query_params.get('hero_id')
    
    if not hero_id:
        return {
            'statusCode': 400,
            'headers': {
                'Access-Control-Allow-Origin': '*', # Enable CORS to prevent browser blocking errors
                'Content-Type': 'application/json'
            },
            'body': json.dumps({'error': 'Parameter hero_id is required!'})
        }
    
    # 2. Query data directly from Amazon DynamoDB using Key Lookups
    dynamodb = boto3.resource('dynamodb', region_name='ap-southeast-1')
    table = dynamodb.Table(DYNAMODB_TABLE)
    
    response = table.get_item(Key={'hero_id': int(hero_id)})
    item = response.get('Item')
    
    if not item:
        return {
            'statusCode': 404,
            'headers': {'Access-Control-Allow-Origin': '*', 'Content-Type': 'application/json'},
            'body': json.dumps({'message': f'Data not found for Hero ID {hero_id}'})
        }
        
    # 3. Return clean JSON results to Frontend
    return {
        'statusCode': 200,
        'headers': {
            'Access-Control-Allow-Origin': '*',
            'Content-Type': 'application/json'
        },
        'body': json.dumps(item)
    }

Configure an API Gateway to expose the Backend Lambda function as a public URL (Endpoint) on the Internet.

Step Action Technical Details
1 Open API Gateway Search for the API Gateway service in the AWS Console.
2 Select API Type Find HTTP API > Click the orange Build button (HTTP API is much cheaper and faster than REST API).
3 Configure Integrations Click Add integration > Select Lambda. Select Region ap-southeast-1 > In the Lambda function field, select dota2-backend-api > Enter API name: dota2-public-api > Click Next.
4 Configure Routes Configure routes: For Method, select GET. For Path, enter /metrics. Keep Target as the Lambda function. Click Next.
5 Keep Default Stage Keep the default Stage as $default (with Auto-deploy enabled). Click Next.
6 Complete Click Create. The system will provide you with a URL string in the Invoke URL field in the format https://xxxx.execute-api.ap-southeast-1.amazonaws.com.
7 Test API Copy the Invoke URL, paste it into the browser, and append: /metrics?hero_id=74. If the screen returns the JSON data like {"hero_id": 74, "win_rate": "52.4"}, you have succeeded!
