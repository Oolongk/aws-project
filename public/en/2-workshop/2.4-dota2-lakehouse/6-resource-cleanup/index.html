Resource Cleanup

You will perform two tasks: Deploy the data collection script to AWS Lambda, and set up an EventBridge Schedule so that it automatically runs at 2:00 AM daily.

Part 1: Create Lambda Ingestion (Replacing the local machine)

Step Action Technical Details
1 Create Lambda Function Access Lambda > Click Create function. Name: dota2-auto-ingestion. Runtime: Python 3.9.
2 Grant S3 Permissions Similar to section 5.1, go to the Configuration tab > Permissions > Open the Role and add an Inline Policy allowing s3:PutObject to the Raw bucket.
3 Insert Source Code Paste the Python code below into the Code Editor. Replace YOUR_RAW_BUCKET with your bucket name. Click Deploy.
4 Configure Timeout Go to the Configuration tab > General configuration > Edit. Increase the Timeout from 3 seconds to 1 minute. Click Save.

Source code for dota2-auto-ingestion (Using default urllib library instead of requests so no Layer is required):

import urllib.request
import boto3
import json
from datetime import datetime

API_URL = "https://api.opendota.com/api/proMatches"
BUCKET_NAME = "YOUR_RAW_BUCKET"
PREFIX = "raw_matches"

def lambda_handler(event, context):
    print("Starting data ingestion from OpenDota API...")
    req = urllib.request.Request(API_URL, headers={'User-Agent': 'Mozilla/5.0'})
    
    with urllib.request.urlopen(req) as response:
        if response.status == 200:
            matches = json.loads(response.read().decode())
            date_str = datetime.now().strftime("%Y-%m-%d")
            file_name = f"matches_{int(datetime.now().timestamp())}.json"
            s3_key = f"{PREFIX}/dt={date_str}/{file_name}"
            
            s3 = boto3.client('s3')
            s3.put_object(Bucket=BUCKET_NAME, Key=s3_key, Body=json.dumps(matches), ContentType='application/json')
            
            return {"status": 200, "message": f"Successfully uploaded {len(matches)} matches to S3"}
        else:
            return {"status": response.status, "message": "API call failed"}

To prevent unexpected charges on AWS, you need to clean up and delete all resources and services created during the project.

Step Action Technical Details
1 Delete DynamoDB Table Open DynamoDB > Tables > Select dota2_hero_metrics table > Click Delete > Type confirm to verify.
2 Delete API Gateway Open API Gateway > Select API dota2-public-api > Click the Delete button in the top right corner > Type confirm to verify.
3 Delete Lambdas & EventBridge In Lambda, delete both functions (dota2-auto-ingestion and dota2-backend-api). In EventBridge, delete the associated schedules/rules.
4 Delete AWS Glue & Athena In AWS Glue, delete the job dota2_etl_job. In Athena, open the Query Editor and run: DROP TABLE dota2_matches;.
5 Clean Up S3 Buckets Go to S3. For each Bucket (Raw, Processed, Athena Results, Frontend), you must first click Empty (type permanently delete to confirm), then click Delete (type the bucket name to confirm).
6 Delete IAM Roles/Users Go to IAM > Delete User dota2-ingestion-bot. Delete Role Glue_Dota2_Processing_Role.

An enterprise-grade Data Pipeline cannot rely on manual operations. In this final chapter, you will deploy the data collection Python script from your local machine to the Cloud and set up Amazon EventBridge to orchestrate the entire workflow of the system.

Once the system is operating smoothly, the documentation will guide you through the process of cleaning up all created resources to prevent unwanted costs on AWS.
