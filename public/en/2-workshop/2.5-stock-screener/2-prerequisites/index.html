Prerequisites

The system architecture is divided into a Data Lake path and a Serving path. The connection point between the two paths is the Lambda QMJ Loader: when S3 creates a new Parquet file, it sends an ObjectCreated event, and the Lambda reads the file and writes the items to DynamoDB.

Data Flow

Data Lake path
Sources  Backfill/Daily Ingestion  S3 Raw  Glue PySpark QMJ  S3 Processed

Serving path
S3 Processed -- ObjectCreated (*.parquet) --> Lambda QMJ Loader --> DynamoDB
DynamoDB --> Lambda Reader --> API Gateway --> Browser

Automation path
EventBridge Scheduler - - - Glue Python Shell Daily Ingestion

Data Contract

Dataset Grain Output location Consumer
us_prices_raw.parquet ticker + price_date raw_us_market/YYYY/MM/DD/ Glue PySpark QMJ
us_company_info.parquet ticker + snapshot_date raw_us_market/YYYY/MM/DD/ Glue PySpark QMJ
us_financials_raw.parquet ticker + report_date + period_type + snapshot_date raw_us_market/YYYY/MM/DD/ Glue PySpark QMJ
QMJ output Parquet One row per ticker on AS_OF_DATE processed_qmj/as_of_date=.../ Lambda QMJ Loader
DynamoDB item ticker + snapshot_date Table qmj_screener Lambda Reader

Architectural Thinking – Event-Driven Serving. qmj_transform.py does not contain PutItem or BatchWriteItem. The transform process finishes at the S3 Processed zone; the Lambda Loader is responsible for loading data into DynamoDB upon detecting a new Parquet file.

Create three separate S3 buckets: Raw, Processed, and Static Website. The Raw and Processed buckets must remain private. The Website bucket will only be made public via CloudFront or a Static Website policy once development is completed.

Create Buckets

Step Action Technical Details
1 Amazon S3 Create bucket Create the Raw Bucket
2 Enter name stock-screener-raw-your-name
3 Select Region ap-southeast-1 or the region you are using for Glue
4 Keep Block Public Access enabled Raw data must not be public
5 Repeat Create stock-screener-processed-your-name
6 Repeat Create stock-screener-web-your-name for the frontend

Prefix Contract

# Raw
raw_us_market/YYYY/MM/DD/us_prices_raw.parquet
raw_us_market/YYYY/MM/DD/us_company_info.parquet
raw_us_market/YYYY/MM/DD/us_financials_raw.parquet

# Processed
processed_qmj/as_of_date=YYYY-MM-DD/part-*.snappy.parquet

# Static frontend
index.html
assets/

Architectural Thinking – Isolation. The browser should never read the Raw or Processed Bucket directly. The browser only loads static assets from the Web Bucket and fetches QMJ data through API Gateway.

Create separate IAM roles for Glue, Lambda Loader, Lambda Reader, and EventBridge Scheduler. Do not hard-code Access Keys in Python source code, Glue arguments, or Lambda environment variables.

Role Matrix

Role Used By Minimum Permissions
AWSGlueServiceRole-StockScreener Daily Ingestion and QMJ Transform Read/Write Raw, Read/Write Processed
LambdaQMJLoaderRole Lambda triggered by S3 List/Get QMJ Parquet, dynamodb:BatchWriteItem, CloudWatch Logs
LambdaStockScreenerReaderRole Lambda Reader dynamodb:Query, CloudWatch Logs
EventBridgeSchedulerStockScreenerRole EventBridge Scheduler glue:StartJobRun for the Daily Ingestion Job

Architectural Thinking – Boundary Per Role. The QMJ Transform job does not need DynamoDB permissions because the source code only writes to S3 Processed. The Lambda Loader is the service authorized to batch write to qmj_screener.

Create Lambda QMJ Loader Role

Step Action Technical Details
1 IAM Roles Create role Select AWS service
2 Select Lambda Trust principal is lambda.amazonaws.com
3 Enter Role name LambdaQMJLoaderRole
4 Attach AWSLambdaBasicExecutionRole Allows Lambda to write logs to CloudWatch Logs
5 Select Create role Create base role
6 Permissions Add permissions Select Create inline policy
7 Select the JSON tab Paste S3 + DynamoDB policy below
8 Replace ACCOUNT_ID Use your AWS Account ID
9 Enter policy name QMJLoaderS3DynamoDBWrite
10 Select Create policy Done 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListProcessedQMJPrefixForBackfill",
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::stock-screener-processed-your-name",
      "Condition": {
        "StringLike": {
          "s3:prefix": ["processed_qmj/*"]
        }
      }
    },
    {
      "Sid": "ReadProcessedQMJParquet",
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::stock-screener-processed-your-name/processed_qmj/*"
    },
    {
      "Sid": "BatchWriteQMJScores",
      "Effect": "Allow",
      "Action": ["dynamodb:BatchWriteItem"],
      "Resource": "arn:aws:dynamodb:ap-southeast-1:ACCOUNT_ID:table/qmj_screener"
    }
  ]
}

}

Architectural Thinking – Retry-Safe Loader. S3 can deliver duplicate events. Lambda Loader uses batch_writer(overwrite_by_pkeys=["ticker", "snapshot_date"]), so writing the same ticker/date again will overwrite the item instead of creating a duplicate logical record.

This chapter covers creating S3 zones, defining the Data Contract, and granting permissions following the Least Privilege principle to Glue, Publisher, Lambda, and EventBridge Scheduler.
