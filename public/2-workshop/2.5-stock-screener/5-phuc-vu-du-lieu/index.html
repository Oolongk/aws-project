Phục vụ dữ liệu

Lambda QMJ Loader ghi một item cho mỗi ticker tại mỗi as_of_date. Lambda Reader query lịch sử theo ticker, vì vậy table dùng ticker làm Partition Key và snapshot_date làm Sort Key.

Bước Hành động Chi tiết kỹ thuật
1 AWS Console DynamoDB Tables Chọn Create table
2 Table name Nhập qmj_screener để khớp default TABLE_NAME trong Lambda Loader
3 Partition key Nhập ticker, type String
4 Sort key Tick Add sort key, nhập snapshot_date, type String
5 Table settings Chọn On-demand cho demo/portfolio khi chưa biết traffic
6 Chọn Create table Chờ Table status thành Active

Tư duy kiến trúc sư – access pattern first. ticker + snapshot_date cho phép Reader Lambda dùng Query để lấy đúng historical series của một mã. Không dùng Scan để phục vụ biểu đồ.

qmj_transform.py ghi Parquet vào processed_qmj/as_of_date=YYYY-MM-DD/. Bài này dùng Lambda QMJ Loader của bạn để nhận S3 ObjectCreated event, đọc part Parquet bằng awswrangler và batch write sang DynamoDB.

Lambda này có hai mode:

Mode Cách gọi Mục đích
s3_trigger S3 tự gửi event khi có .parquet mới Nạp incremental output mới từ Glue PySpark
backfill Lambda Test Event hoặc Invoke API Quét toàn bộ processed_qmj/ và nạp historical QMJ

Tư duy kiến trúc sư – source boundary. Đây không phải Glue Publisher Job. S3 là event source, Lambda là compute layer nạp Serving Store, còn DynamoDB là read-optimized projection cho website.

Lambda Loader source code

Dòng import json được thêm vì source cần json.dumps(response) khi có failed_files.

import json
import os
import re
import math
import boto3
import urllib.parse
import awswrangler as wr
import pandas as pd

from datetime import date, datetime
from decimal import Decimal
from numbers import Integral, Real

TABLE_NAME = os.environ.get("TABLE_NAME", "qmj_screener")
PROCESSED_BUCKET = os.environ.get(
    "PROCESSED_BUCKET",
    "stock-screener-processed-tên-của-bạn"
)
PROCESSED_PREFIX = os.environ.get(
    "PROCESSED_PREFIX",
    "processed_qmj/"
)

dynamodb = boto3.resource("dynamodb")
s3 = boto3.client("s3")
table = dynamodb.Table(TABLE_NAME)


def to_dynamodb_value(value):
    # Chuẩn hóa Pandas/NumPy value về type DynamoDB chấp nhận.
    if value is None:
        return None

    try:
        if bool(pd.isna(value)):
            return None
    except Exception:
        pass

    if isinstance(value, (datetime, date)):
        return value.strftime("%Y-%m-%d")

    if isinstance(value, bool):
        return value

    if isinstance(value, Decimal):
        return value

    if isinstance(value, Integral):
        return Decimal(str(int(value)))

    if isinstance(value, Real):
        number = float(value)
        if not math.isfinite(number):
            return None
        return Decimal(str(number))

    if isinstance(value, str):
        return value

    return str(value)


def extract_as_of_date(s3_key):
    # Lấy partition date từ processed_qmj/as_of_date=YYYY-MM-DD/.
    match = re.search(
        r"(?:^|/)as_of_date=(\d{4}-\d{2}-\d{2})(?:/|$)",
        s3_key
    )

    if not match:
        raise ValueError(f"Không tìm thấy as_of_date trong key: {s3_key}")

    as_of_date = match.group(1)
    datetime.strptime(as_of_date, "%Y-%m-%d")
    return as_of_date


def load_parquet_to_dynamodb(bucket, key):
    as_of_date = extract_as_of_date(key)
    s3_path = f"s3://{bucket}/{key}"
    df = wr.s3.read_parquet(path=s3_path)

    if df.empty:
        return 0, 0

    if "ticker" not in df.columns:
        raise ValueError(f"File không có cột ticker: {s3_path}")

    loaded_rows = 0
    skipped_rows = 0
    columns = list(df.columns)

    # Overwrite cùng ticker + snapshot_date để retry event không tạo duplicate logical item.
    with table.batch_writer(
        overwrite_by_pkeys=["ticker", "snapshot_date"]
    ) as batch:
        for values in df.itertuples(index=False, name=None):
            item = {}

            for column, value in zip(columns, values):
                clean_value = to_dynamodb_value(value)
                if clean_value is not None:
                    item[column] = clean_value

            ticker = str(item.get("ticker", "")).strip().upper()
            if not ticker:
                skipped_rows += 1
                continue

            item["ticker"] = ticker
            item["snapshot_date"] = as_of_date
            item["as_of_date"] = as_of_date
            item["source_s3_key"] = key

            batch.put_item(Item=item)
            loaded_rows += 1

    return loaded_rows, skipped_rows


def get_existing_parquet_files(bucket, prefix):
    keys = []
    paginator = s3.get_paginator("list_objects_v2")

    for page in paginator.paginate(Bucket=bucket, Prefix=prefix):
        for obj in page.get("Contents", []):
            key = obj["Key"]
            if key.endswith(".parquet"):
                keys.append(key)

    return sorted(keys)


def process_files(bucket, keys):
    processed_files = 0
    loaded_rows = 0
    skipped_rows = 0
    failed_files = []

    for key in keys:
        try:
            loaded, skipped = load_parquet_to_dynamodb(bucket, key)
            processed_files += 1
            loaded_rows += loaded
            skipped_rows += skipped
        except Exception as error:
            failed_files.append({"key": key, "error": str(error)})

    return {
        "processed_files": processed_files,
        "loaded_rows": loaded_rows,
        "skipped_rows": skipped_rows,
        "failed_files": failed_files
    }


def lambda_handler(event, context):
    event = event or {}

    # Manual backfill mode: quét toàn bộ QMJ Parquet trong Processed Zone.
    if event.get("mode") == "backfill":
        bucket = event.get("bucket", PROCESSED_BUCKET)
        prefix = event.get("prefix", PROCESSED_PREFIX)
        keys = get_existing_parquet_files(bucket, prefix)

        if not keys:
            return {
                "mode": "backfill",
                "processed_files": 0,
                "loaded_rows": 0,
                "skipped_rows": 0,
                "failed_files": []
            }

        result = process_files(bucket, keys)
        result["mode"] = "backfill"
        result["total_parquet_files_found"] = len(keys)
        return result

    # S3 trigger mode: lọc event ObjectCreated trong prefix Processed QMJ.
    keys_by_bucket = {}

    for record in event.get("Records", []):
        if record.get("eventSource") != "aws:s3":
            continue

        if not record.get("eventName", "").startswith("ObjectCreated:"):
            continue

        bucket = record["s3"]["bucket"]["name"]
        key = urllib.parse.unquote_plus(record["s3"]["object"]["key"])

        if not key.startswith(PROCESSED_PREFIX) or not key.endswith(".parquet"):
            continue

        keys_by_bucket.setdefault(bucket, []).append(key)

    total_processed_files = 0
    total_loaded_rows = 0
    total_skipped_rows = 0
    failed_files = []

    for bucket, keys in keys_by_bucket.items():
        result = process_files(bucket, keys)
        total_processed_files += result["processed_files"]
        total_loaded_rows += result["loaded_rows"]
        total_skipped_rows += result["skipped_rows"]
        failed_files.extend(result["failed_files"])

    response = {
        "mode": "s3_trigger",
        "processed_files": total_processed_files,
        "loaded_rows": total_loaded_rows,
        "skipped_rows": total_skipped_rows,
        "failed_files": failed_files
    }

    if failed_files:
        raise Exception(json.dumps(response))

    return response

Lambda source code

import json
import os
from decimal import Decimal

import boto3
from boto3.dynamodb.conditions import Key

TABLE_NAME = os.environ["DYNAMODB_TABLE"]
table = boto3.resource("dynamodb").Table(TABLE_NAME)


def json_default(value):
    # DynamoDB trả Decimal; API response cần JSON number.
    if isinstance(value, Decimal):
        return float(value)
    raise TypeError(f"Unsupported type: {type(value)}")


def response(status_code, body):
    return {
        "statusCode": status_code,
        "headers": {
            "Content-Type": "application/json",
            "Access-Control-Allow-Origin": "*",
            "Access-Control-Allow-Methods": "GET,OPTIONS",
            "Access-Control-Allow-Headers": "Content-Type"
        },
        "body": json.dumps(body, default=json_default)
    }


def lambda_handler(event, context):
    params = event.get("queryStringParameters") or {}
    ticker = (params.get("ticker") or "").strip().upper()

    if not ticker:
        return response(400, {"message": "ticker is required"})

    result = table.query(
        KeyConditionExpression=Key("ticker").eq(ticker),
        ScanIndexForward=True
    )

    return response(200, {
        "ticker": ticker,
        "items": result.get("Items", [])
    })

Tư duy kiến trúc sư – query not scan. Reader chỉ có quyền dynamodb:Query. Không cấp dynamodb:Scan, không cần S3 permission và không dùng Loader Role.

    // ==========================================
    // ĐIỀN LINK API GATEWAY CỦA BẠN VÀO ĐÂY
    // ==========================================
    const API_URL = "xxxxxxxxxxxxxxxxxxxxx";
    
    let allData = []; // Lưu toàn bộ dữ liệu lịch sử
    let dataTableInstance = null;

    function getScoreColorClass(score) {
        if (score === null || score === undefined) return "text-secondary";
        if (score >= 80) return "score-excellent";
        if (score >= 60) return "score-good";
        if (score >= 40) return "score-average";
        return "score-bad";
    }

    function formatNumber(num) {
        if (!num) return "-";
        return Number(num).toLocaleString('vi-VN', { maximumFractionDigits: 1 });
    }

    async function initApp() {
        try {
            const response = await fetch(API_URL);
            allData = await response.json();
            
            // Lọc data hợp lệ
            allData = allData.filter(s => s.ticker != null);
            
            // 1. Trích xuất danh sách các Ngày/Quý duy nhất (Xóa trùng lặp và Sắp xếp mới nhất lên đầu)
            const uniqueDates = [...new Set(allData.map(item => item.snapshot_date))].filter(Boolean).sort().reverse();
            
            // 2. Đổ các ngày vào Dropdown
            const dateSelector = document.getElementById("dateSelector");
            dateSelector.innerHTML = ""; // Xóa chữ "Đang tải..."
            
            if(uniqueDates.length > 0) {
                uniqueDates.forEach(date => {
                    let option = document.createElement("option");
                    option.value = date;
                    option.innerText = date;
                    dateSelector.appendChild(option);
                });

                // Lắng nghe sự kiện khi người dùng chọn một Quý khác
                dateSelector.addEventListener("change", function(e) {
                    renderTableForDate(e.target.value);
                });

                // Tự động hiển thị dữ liệu của ngày mới nhất
                renderTableForDate(uniqueDates[0]);
            } else {
                dateSelector.innerHTML = "<option>Không có dữ liệu</option>";
            }
            
            // Tắt màn hình loading
            document.getElementById("loading-screen").style.display = "none";

        } catch (error) {
            document.getElementById("loading-screen").innerHTML = `
                <h3 class="text-danger">Lỗi kết nối API</h3>
                <p class="text-secondary">${error.message}</p>
            `;
        }
    }

    // Hàm Lọc và Vẽ lại bảng dựa trên ngày được chọn
    function renderTableForDate(selectedDate) {
        // Lọc dữ liệu của ngày đang chọn
        let filteredData = allData.filter(item => item.snapshot_date === selectedDate);
        
        // Sắp xếp theo Rank
        filteredData.sort((a, b) => (a.qmj_rank || 999) - (b.qmj_rank || 999));

        // Hủy bảng cũ trước khi vẽ bảng mới (Ngăn lỗi DataTables)
        if (dataTableInstance !== null) {
            dataTableInstance.destroy();
        }

        const tbody = document.querySelector("#stockTable tbody");
        tbody.innerHTML = ""; // Xóa dữ liệu cũ
        
        filteredData.forEach(stock => {
            const tr = document.createElement("tr");
            
            let exchangeClass = "";
            if(stock.exchange === "HSX") exchangeClass = "exchange-HSX";
            else if(stock.exchange === "HNX") exchangeClass = "exchange-HNX";
            else exchangeClass = "exchange-UPCOM";

            tr.innerHTML = `
                <td class="text-center text-secondary fw-bold">${stock.qmj_rank || '-'}</td>
                <td><span class="ticker-badge ${exchangeClass}">${stock.ticker}</span></td>
                <td class="text-secondary small fw-bold">${stock.exchange || '-'}</td>
                <td class="text-truncate" style="max-width: 180px;" title="${stock.company_name || '-'}">${stock.company_name || '-'}</td>
                <td class="text-truncate" style="max-width: 150px;">${stock.industry_group || '-'}</td>
                <td class="text-truncate text-secondary" style="max-width: 150px;">${stock.sector_detail || '-'}</td>
                <td class="text-end fw-semibold">${formatNumber(stock.current_market_cap)}</td>
                <td class="text-end text-muted small">${formatNumber(stock.quarter_market_cap)}</td>
                
                <td class="text-center fs-6 border-start border-secondary ${getScoreColorClass(stock.qmj_score)}">${stock.qmj_score ? Number(stock.qmj_score).toFixed(1) : '-'}</td>
                <td class="text-center ${getScoreColorClass(stock.qmj_profitability)}">${stock.qmj_profitability ? Number(stock.qmj_profitability).toFixed(1) : '-'}</td>
                <td class="text-center ${getScoreColorClass(stock.qmj_growth)}">${stock.qmj_growth ? Number(stock.qmj_growth).toFixed(1) : '-'}</td>
                <td class="text-center ${getScoreColorClass(stock.qmj_safety)}">${stock.qmj_safety ? Number(stock.qmj_safety).toFixed(1) : '-'}</td>
                <td class="text-center ${getScoreColorClass(stock.value_recent_score)}">${stock.value_recent_score ? Number(stock.value_recent_score).toFixed(1) : '-'}</td>
                <td class="text-center ${getScoreColorClass(stock.momentum_recent_score)}">${stock.momentum_recent_score ? Number(stock.momentum_recent_score).toFixed(1) : '-'}</td>
            `;
            tbody.appendChild(tr);
        });

        // Khởi tạo lại DataTables
        dataTableInstance = $('#stockTable').DataTable({
            pageLength: 20,
            lengthMenu: [20, 50, 100, 500],
            scrollX: true, 
            language: {
                search: "Lọc cổ phiếu:",
                lengthMenu: "Hiển thị _MENU_ mã",
                info: "Đang hiển thị _START_ đến _END_ trên tổng _TOTAL_ mã",
                paginate: { next: "Sau", previous: "Trước" },
                zeroRecords: "Không tìm thấy mã cổ phiếu nào."
            },
            order: [[0, 'asc']], 
            columnDefs: [
                { orderable: false, targets: [3, 4, 5] } 
            ]
        });
    }

Tư duy kiến trúc sư – serving separation. Browser không tải Parquet từ S3 Processed. Parquet được publish sang DynamoDB, rồi API chỉ trả JSON fields cần cho biểu đồ.

Chương này đưa QMJ Parquet từ S3 Processed lên website bằng kiến trúc event-driven: S3 trigger Lambda QMJ Loader, Loader ghi DynamoDB, Lambda Reader query theo ticker, API Gateway trả JSON và Web Frontend vẽ Chart.js.

Scheduler khởi chạy Glue Python Shell Job hằng ngày. Không cấu hình scheduler chạy cùng lúc transform/publisher vì cần đợi Raw output hoàn chỉnh.
