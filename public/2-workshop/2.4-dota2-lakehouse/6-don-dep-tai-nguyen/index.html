Dọn dẹp tài nguyên

Em sẽ thực hiện hai tác vụ: Đưa script lấy dữ liệu lên AWS Lambda, và thiết lập EventBridge Schedule để hệ thống tự động chạy vào lúc 2 giờ sáng mỗi ngày.

Phần 1: Tạo Lambda Ingestion (Thay thế cho máy tính cá nhân)

Bước Hành động Chi tiết kỹ thuật
1 Tạo Hàm Lambda Truy cập Lambda > Nhấn Create function. Đặt tên: dota2-auto-ingestion. Runtime: Python 3.9.
2 Cấp quyền S3 Tương tự bài 5.1, vào tab Configuration > Permissions > Mở Role và thêm Inline Policy cho phép s3:PutObject vào bucket Raw.
3 Chèn mã nguồn Dán đoạn mã Python bên dưới vào Code Editor. Thay YOUR_RAW_BUCKET bằng tên bucket của em. Nhấn Deploy.
4 Cấu hình Timeout Sang tab Configuration > General configuration > Edit. Tăng Timeout từ 3 giây lên 1 phút. Nhấn Save.

Mã nguồn dota2-auto-ingestion (Dùng thư viện urllib mặc định thay vì requests để không cần cài Layer):

import urllib.request
import boto3
import json
from datetime import datetime

API_URL = "https://api.opendota.com/api/proMatches"
BUCKET_NAME = "YOUR_RAW_BUCKET"
PREFIX = "raw_matches"

def lambda_handler(event, context):
    print("Bắt đầu lấy dữ liệu từ OpenDota API...")
    req = urllib.request.Request(API_URL, headers={'User-Agent': 'Mozilla/5.0'})
    
    with urllib.request.urlopen(req) as response:
        if response.status == 200:
            matches = json.loads(response.read().decode())
            date_str = datetime.now().strftime("%Y-%m-%d")
            file_name = f"matches_{int(datetime.now().timestamp())}.json"
            s3_key = f"{PREFIX}/dt={date_str}/{file_name}"
            
            s3 = boto3.client('s3')
            s3.put_object(Bucket=BUCKET_NAME, Key=s3_key, Body=json.dumps(matches), ContentType='application/json')
            
            return {"status": 200, "message": f"Đã đẩy {len(matches)} trận lên S3"}
        else:
            return {"status": response.status, "message": "Lỗi gọi API"}

Để tránh phát sinh chi phí ngoài ý muốn trên AWS, em cần tiến hành xóa bỏ toàn bộ các tài nguyên và dịch vụ đã tạo ra trong quá trình thực hiện dự án.

Bước Hành động Chi tiết kỹ thuật
1 Xóa bảng DynamoDB Mở DynamoDB > Tables > Tích chọn bảng dota2_hero_metrics > Chọn Delete > Gõ chữ confirm để xác nhận.
2 Xóa API Gateway Mở API Gateway > Chọn API dota2-public-api > Nút Delete góc phải trên cùng > Gõ chữ confirm để xác nhận.
3 Xóa Lambdas & EventBridge Vào Lambda, xóa cả 2 functions (dota2-auto-ingestion và dota2-backend-api). Vào EventBridge, xóa cả hai rules/schedules.
4 Xóa AWS Glue & Athena Vào AWS Glue xóa Job dota2_etl_job. Vào Athena, mở Query Editor và chạy lệnh DROP TABLE dota2_matches;.
5 Dọn dẹp các S3 Bucket Vào S3. Đối với từng S3 Bucket (Raw, Processed, Athena Results, Frontend), em cần chọn Empty (nhập permanently delete để xác nhận) trước, sau đó mới tiến hành Delete (nhập tên bucket để xác nhận).
6 Xóa IAM Roles/Users Vào IAM > Xóa User dota2-ingestion-bot. Xóa Role Glue_Dota2_Processing_Role.

Một Data Pipeline chuẩn Enterprise không thể phụ thuộc vào việc con người thao tác thủ công. Trong chương cuối cùng này, em sẽ đưa mã nguồn Python thu thập dữ liệu từ máy tính cá nhân lên Cloud và thiết lập Amazon EventBridge làm nhạc trưởng điều phối toàn bộ luồng chạy của hệ thống.

Sau khi hệ thống đã vận hành trơn tru, tài liệu sẽ hướng dẫn em quy trình dọn dẹp sạch toàn bộ tài nguyên đã tạo để tránh phát sinh chi phí ngoài ý muốn trên AWS.
