Tổng quan

Thực hiện tạo Amazon S3 Bucket đóng vai trò là “Vùng hạ cánh” (Landing Zone) để chứa dữ liệu JSON thô.

Bước Hành động Chi tiết kỹ thuật
1 Truy cập AWS Console Đăng nhập và tìm kiếm dịch vụ S3.
2 Khởi tạo Bucket Click nút Create bucket màu cam.
3 Cấu hình General Tên bucket: dota2-raw-zone-tencuaban (tên phải viết thường, không dấu, duy nhất). Region: ap-southeast-1 (Singapore).
4 Cấu hình Object Ownership Giữ nguyên ACLs disabled (recommended).
5 Cấu hình Block Public Access Tích chọn Block all public access để bảo mật an toàn tuyệt đối.
6 Hoàn tất Cuộn xuống cuối và nhấn Create bucket.

Để Python script có thể đẩy dữ liệu lên S3, nó cần một bộ chìa khóa (Access Key). Em sẽ tạo một IAM User và chỉ cấp đúng quyền ghi file vào Raw Bucket.

Bước Hành động Chi tiết kỹ thuật
1 Truy cập IAM Tìm dịch vụ IAM > Chọn Users > Nhấn Create user.
2 Nhập thông tin User User name: dota2-ingestion-bot. Bỏ qua tùy chọn Provide user access to the AWS Management Console. Nhấn Next.
3 Khởi tạo Policy Ở màn hình Permissions, chọn Attach policies directly > Nhấn Create policy (hệ thống sẽ mở tab mới).
4 Cấu hình Policy (JSON) Chuyển sang định dạng JSON và dán đoạn mã phân quyền bên dưới vào > Nhấn Next.
5 Lưu Policy Tên Policy: S3_PutObject_Dota2_Raw. Nhấn Create policy.
6 Gắn Policy cho User Quay lại tab tạo User, nhấn nút Refresh, tìm và tích chọn S3_PutObject_Dota2_Raw > Nhấn Next > Create user.
7 Sinh Access Key Chọn User vừa tạo > Tab Security credentials > Nhấn Create access key > Chọn Local code. Tải file .csv chứa cặp Access Key và Secret Key về máy.

Mã JSON Policy (Nhớ thay thế phần YOUR_BUCKET_NAME bằng tên bucket em vừa tạo ở bài 1.1):

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
        }
    ]
}

Em sẽ viết một mã nguồn Python để đóng vai trò Ingestion Bot: gọi OpenDota API, lấy 100 trận đấu chuyên nghiệp mới nhất và tải tệp JSON đó lên S3.

Bước Hành động Chi tiết kỹ thuật
1 Chuẩn bị môi trường Mở Terminal (Command Prompt), cài đặt thư viện AWS: pip install boto3 requests
2 Nạp chìa khóa IAM Gõ lệnh aws configure. Lần lượt dán Access Key, Secret Key vừa lấy ở Bài 1.2. Chọn Region là ap-southeast-1.
3 Viết mã nguồn Tạo một file tên dota2_ingestion.py và dán đoạn code bên dưới vào. (Nhớ sửa tên BUCKET_NAME).
4 Chạy Script Gõ lệnh python dota2_ingestion.py trên Terminal.
5 Kiểm duyệt (Validate) Truy cập AWS Console > S3 > Mở Raw Bucket. Em sẽ thấy một cấu trúc thư mục mới được tạo tự động chứa file JSON.

Mã nguồn dota2_ingestion.py:

import requests
import boto3
import json
from datetime import datetime

# Cấu hình API và S3
API_URL = "https://api.opendota.com/api/proMatches"
BUCKET_NAME = "dota2-raw-zone-tencuaban" # Thay bằng tên S3 Raw Bucket của em
PREFIX = "raw_matches"

def fetch_and_upload():
    print("Đang gọi OpenDota API...")
    response = requests.get(API_URL)
    
    if response.status_code == 200:
        matches = response.json()
        
        # Tạo đường dẫn theo chuẩn Apache Hive Partitioning (dt=YYYY-MM-DD)
        date_str = datetime.now().strftime("%Y-%m-%d")
        file_name = f"matches_{int(datetime.now().timestamp())}.json"
        s3_key = f"{PREFIX}/dt={date_str}/{file_name}"
        
        # PutObject lên Amazon S3
        s3 = boto3.client('s3')
        s3.put_object(
            Bucket=BUCKET_NAME,
            Key=s3_key,
            Body=json.dumps(matches),
            ContentType='application/json'
        )
        print(f"Thành công! Đã đẩy {len(matches)} trận đấu lên S3 tại: {s3_key}")
    else:
        print("Lỗi API:", response.status_code)

if __name__ == "__main__":
    fetch_and_upload()

Nhiệm vụ của tầng này là tự động hóa việc kết nối đến OpenDota API, lấy dữ liệu trận đấu dạng JSON nguyên bản (Raw) và đẩy thẳng vào vùng hạ cánh (Landing Zone) trên Amazon S3.

Em sẽ thiết lập hạ tầng với tiêu chuẩn bảo mật tối thiểu (Least Privilege) trước khi viết mã nguồn thu thập dữ liệu.
