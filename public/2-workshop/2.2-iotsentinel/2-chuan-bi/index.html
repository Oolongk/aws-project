Thiết lập môi trường Python

Để chạy được mã nguồn giả lập xe tải, máy tính của em cần được cài đặt Python và thư viện kết nối IoT của AWS.

  1. Kiểm tra phiên bản Python trên máy tính bằng cách mở Terminal/Command Prompt và gõ lệnh: python --version (Yêu cầu phiên bản 3.9 trở lên).

  1. Cài đặt Python (Dành cho máy chưa cài đặt):

    • Với Windows: Truy cập trang python.org/downloads, tải bộ cài đặt mới nhất.

      Lưu ý quan trọng: Ở màn hình cài đặt đầu tiên, em BẮT BUỘC phải tích chọn ô “Add Python.exe to PATH” trước khi nhấn Install Now. Điều này giúp Terminal nhận diện được lệnh python.

    • Với macOS (Dùng Homebrew): 
      brew install python
    • Với Linux (Ubuntu/Debian): 
      sudo apt update && sudo apt install python3 python3-pip -y

  2. Cài đặt thư viện AWSIoTPythonSDK. Đây là thư viện quan trọng nhất để thực hiện giao tiếp MQTT. Chạy lệnh:

    pip install AWSIoTPythonSDK

Tạo file mã nguồn giả lập

Chúng ta sẽ tạo một file Python đóng vai trò là cảm biến thông minh trên xe tải. File này có nhiệm vụ mô phỏng dữ liệu hành trình của 10 xe tải và gửi lên AWS Cloud qua giao thức MQTT.

  1. Mở trình soạn thảo VS Code.
  2. Tạo một file mới với tên truck_simulator.py.
  3. Copy và dán đoạn mã dưới đây vào file:
import time
import json
import random
from AWSIoTPythonSDK.MQTTLib import AWSIoTMQTTClient

# ==========================================
#  CẤU HÌNH THÔNG SỐ (SẼ CẬP NHẬT Ở CHƯƠNG 2)
# ==========================================
# Endpoint này sẽ lấy từ AWS IoT Core Settings
IOT_ENDPOINT = "YOUR_AWS_IOT_ENDPOINT" 

# Đường dẫn đến các chứng chỉ bảo mật
PATH_TO_ROOT_CA = "certs/AmazonRootCA1.pem"
PATH_TO_CERT = "certs/your-certificate.pem.crt"
PATH_TO_PRIVATE_KEY = "certs/your-private.pem.key"

CLIENT_ID = "Vaccine_Fleet_Simulator"
TOPIC = "telemetry/trucks"

# Tạo danh sách giả lập 10 xe tải với tọa độ gốc
TRUCKS = [{"id": f"T-{100+i}", "lat": 10.7626 + (i * 0.01), "lon": 106.6602 - (i * 0.01)} for i in range(10)]

# ==========================================
# KHỞI TẠO KẾT NỐI MQTT BẢO MẬT
# ==========================================
myMQTTClient = AWSIoTMQTTClient(CLIENT_ID)
myMQTTClient.configureEndpoint(IOT_ENDPOINT, 8883)
myMQTTClient.configureCredentials(PATH_TO_ROOT_CA, PATH_TO_PRIVATE_KEY, PATH_TO_CERT)

print(f"Đang kết nối đến AWS IoT Core...")

# ==========================================
# VÒNG LẶP GỬI DỮ LIỆU (1 GIÂY/LẦN)
# ==========================================
try:
    myMQTTClient.connect()
    print(" Kết nối thành công!\n")
    while True:
        for truck in TRUCKS:
            # Sinh dữ liệu ngẫu nhiên cho nhiệt độ và vị trí
            data = {
                "truck_id": truck["id"],
                "temperature": round(random.uniform(2.0, 8.0), 2),
                "latitude": round(truck["lat"] + random.uniform(-0.001, 0.001), 6),
                "longitude": round(truck["lon"] + random.uniform(-0.001, 0.001), 6),
                "timestamp_ms": int(time.time() * 1000)
            }
            
            payload = json.dumps(data)
            myMQTTClient.publish(TOPIC, payload, 1)
            print(f"[{truck['id']}] Đã gửi: {payload}")
            
        time.sleep(1) 

except KeyboardInterrupt:
    print("\n Đã dừng gửi dữ liệu.")
    myMQTTClient.disconnect()

  1. Lưu file vào thư mục dự án của em.

Lưu ý: Em cần thay thế YOUR_AWS_IOT_ENDPOINT và tên các file chứng chỉ bằng thông tin thật mà em sẽ khởi tạo trong phần Triển khai hệ thống tiếp theo.

Các bước chuẩn bị

Để xây dựng hệ thống giám sát xe tải thời gian thực, chúng ta cần chuẩn bị một “nguồn phát dữ liệu” giả lập và thiết lập môi trường lập trình trên máy tính cá nhân. Do không có thiết bị phần cứng thật, chúng ta sẽ dùng Python để mô phỏng 10 chiếc xe tải thông minh.

  • Python & AWSIoTPythonSDK: Đây là bộ công cụ chính để biến máy tính của em thành một thiết bị IoT Edge. Thư viện này giúp kết nối bảo mật qua giao thức MQTT với AWS Cloud, mã hóa dữ liệu và gửi thông tin nhiệt độ lên hệ thống.

  • AWS Region (Singapore - ap-southeast-1): Để tối ưu tốc độ và chi phí, chúng ta sẽ thống nhất triển khai toàn bộ tài nguyên tại vùng Singapore. Việc chọn đúng Region ngay từ đầu giúp các dịch vụ như SQS, Lambda và DynamoDB có thể liên kết với nhau một cách tự động và an toàn.

Việc chuẩn bị kỹ lưỡng môi trường giả lập là bước đệm quan trọng để dòng dữ liệu có thể chảy suôn sẻ vào Pipeline ở các bước tiếp theo.
