We will deploy the static website interface source code (HTML/JS) to a dedicated S3 Bucket configured with Static Website Hosting.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Create UI Bucket | Go to **S3 Console**, create a new bucket named: `dota2-frontend-site-yourname`. |
| 2 | Disable Block Public Access | Because this is a public website, under *Block Public Access*, **UNCHECK** the *Block all public access* box. Click Create bucket. |
| 3 | Configure Web Hosting | Open the newly created Bucket > Select the **Properties** tab > Scroll down to the **Static website hosting** section > Click **Edit** > Select **Enable**. |
| 4 | Specify Default File | In the *Index document* field, enter `index.html`. Click **Save changes**. The system provides a website endpoint URL at the bottom of this section. |
| 5 | Create Local Source | On your local machine, create a file named `index.html` and paste the HTML/JS code block below into it. (Remember to replace the `API_GATEWAY_URL` variable with your Invoke URL obtained in step 5.2). |
| 6 | Upload File to S3 | Return to S3 Console > **Objects** tab > Click **Upload** and upload the `index.html` file. |
| 7 | Configure Bucket Policy | Switch to the **Permissions** tab > Under **Bucket policy** > Click **Edit** and paste the JSON policy below to grant public read access > Click **Save changes**. |

JSON Bucket Policy Code (Remember to replace `dota2-frontend-site-yourname` with your bucket name):
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::dota2-frontend-site-yourname/*"
        }
    ]
}
```
