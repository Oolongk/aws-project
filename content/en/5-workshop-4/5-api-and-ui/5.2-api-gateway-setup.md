We proceed to set up an API Gateway endpoint to expose the Backend Lambda function as a public URL endpoint on the Internet.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Open API Gateway | Search for the **API Gateway** service in the AWS Console. |
| 2 | Select API Type | Find **HTTP API** > Click the orange **Build** button (HTTP APIs are faster and significantly cheaper than REST APIs). |
| 3 | Configure Integrations | Click *Add integration* > Select **Lambda**. Select Region `ap-southeast-1` > In the *Lambda function* field, select `dota2-backend-api` > Enter API name: `dota2-public-api` > Click **Next**. |
| 4 | Configure Routes | Configure routes: Method: select **GET**. Path: enter `/metrics`. Target: keep the Lambda function. Click **Next**. |
| 5 | Keep Default Stage | Under Stages, keep the default `$default` (Auto-deploy enabled). Click **Next**. |
| 6 | Complete | Click **Create**. The system provides an **Invoke URL** string formatted as `https://xxxx.execute-api.ap-southeast-1.amazonaws.com`. |
| 7 | Test the API | Copy the Invoke URL into your browser and append: `/metrics?hero_id=74`. If the screen returns a JSON response like `{"hero_id": 74, "win_rate": "52.4"}`, you are 100% successful! |
