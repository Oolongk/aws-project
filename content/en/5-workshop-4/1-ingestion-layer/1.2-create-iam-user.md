For the Python script to push data to S3, it needs a set of keys (Access Key). We will create an IAM User and grant only the exact permissions needed to write files into the Raw Bucket.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Access IAM | Find the **IAM** service > Select **Users** > Click **Create user**. |
| 2 | Enter User information | User name: `dota2-ingestion-bot`. Skip the *Provide user access to the AWS Management Console* option. Click **Next**. |
| 3 | Initialize Policy | On the Permissions screen, select **Attach policies directly** > Click **Create policy** (the system will open a new tab). |
| 4 | Configure Policy (JSON) | Switch to **JSON** format and paste the permissions code below > Click **Next**. |
| 5 | Save Policy | Policy name: `S3_PutObject_Dota2_Raw`. Click **Create policy**. |
| 6 | Attach Policy to User | Return to the Create User tab, click the *Refresh* button, find and check `S3_PutObject_Dota2_Raw` > Click **Next** > **Create user**. |
| 7 | Generate Access Key | Click into the newly created User > **Security credentials** tab > Click **Create access key** > Select *Local code*. Download the `.csv` file containing the Access Key and Secret Key pair to your machine. |

JSON Policy Code (Remember to replace `YOUR_BUCKET_NAME` with the bucket name you created in section 1.1):

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
        }
    ]
}
```
