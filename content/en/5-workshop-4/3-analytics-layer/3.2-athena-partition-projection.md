Typically, users use **AWS Glue Crawler** to automatically discover file structure and create tables. However, Crawlers are slow and costly. Instead, we will write a direct DDL (Data Definition Language) statement with embedded **Partition Projection** technique to create the table. This technique enables Athena to calculate partitions extremely fast without requiring a Crawler.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Open Query Editor | In the Athena interface, switch to the **Query editor** tab. |
| 2 | Run DDL | Copy the SQL code below, paste it into the query editor (replace the `LOCATION` path with your S3 Processed Bucket) and click **Run**. |
| 3 | Test Query | Delete the old command, type a new command: `SELECT * FROM dota2_matches LIMIT 10;` and click **Run** to see the results. |

**DDL SQL code with Partition Projection:**

```sql
CREATE EXTERNAL TABLE IF NOT EXISTS dota2_matches (
  `match_id` BIGINT,
  `account_id` BIGINT,
  `hero_id` INT,
  `is_win` BOOLEAN
)
PARTITIONED BY (
  `match_date` STRING
)
STORED AS PARQUET
LOCATION 's3://dota2-processed-zone-yourname/matches_parquet/'
TBLPROPERTIES (
  'projection.enabled' = 'true',
  'projection.match_date.type' = 'date',
  'projection.match_date.range' = '2025-01-01,NOW',
  'projection.match_date.format' = 'yyyy-MM-dd',
  'projection.match_date.interval' = '1',
  'projection.match_date.interval.unit' = 'DAYS',
  'storage.location.template' = 's3://dota2-processed-zone-yourname/matches_parquet/match_date=${match_date}/'
);
```
