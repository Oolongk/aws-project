This article guides you to configure the core data processing block (Core ETL Compute Layer). We will write a Python script executing on AWS Lambda to control the Amazon Athena service to run Serverless SQL queries, cast Parquet data types, and extract timestamps to native integers for AI.

#### AWS Lambda compute function configuration guide

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Initialize function | Go to the **AWS Lambda** service -> Click **Create function** -> Select **Author from scratch**. |
| **2** | Basic setup | Name the function `AthenaETLProcessor`. Select the language Runtime as **Python 3.12**. |
| **3** | Configure time | Switch to the **Configuration** tab -> **General configuration** section -> Click Edit, increase the **Timeout** parameter to a minimum of `2 minutes` (to avoid the function being interrupted while waiting for Athena to export the file). |
| **4** | Grant system permissions | In the **Permissions** section, click on the Execution Role link to open the IAM interface. Proceed to attach 2 standard permission policies: `AmazonAthenaFullAccess` and `AmazonS3FullAccess`. |

#### ETL Processing Source Code (Python & Serverless SQL)

Please return to the **Code** tab of the Lambda function, clear the default code, paste the entire Enterprise standard source code block below and click the orange **Deploy** button:

```python
import boto3
import time

def lambda_handler(event, context):
    athena_client = boto3.client('athena')
    
    # Define database configuration and destination folder
    DATABASE = 'clickstream_db'
    # ⚠️ Note: Accurately replace your S3 Bucket Data Lake name in the line below
    OUTPUT_LOCATION = 's3://your-clickstream-datalake-bucket-name/personalize_data/' 
    
    # SQL query to extract Parquet, capitalize column headers and convert time format to UNIX Epoch Time
    query = """
    SELECT 
        user_id AS USER_ID,
        page_url AS ITEM_ID,
        CAST(to_unixtime(CAST(event_timestamp AS timestamp)) AS bigint) AS "TIMESTAMP",
        event_type AS EVENT_TYPE,
        device_os AS DEVICE_OS
    FROM "clickstream_db"."crawled_data"
    WHERE user_id IS NOT NULL;
    """
    
    print("🚀 Waking up Amazon Athena to execute Serverless SQL ETL query...")
    response = athena_client.start_query_execution(
        QueryString=query,
        QueryExecutionContext={'Database': DATABASE},
        ResultConfiguration={'OutputLocation': OUTPUT_LOCATION}
    )
    
    query_execution_id = response['QueryExecutionId']
    
    # Polling Loop technique to check Athena's asynchronous status
    state = 'RUNNING'
    while state in ['RUNNING', 'QUEUED']:
        check_status = athena_client.get_query_execution(QueryExecutionId=query_execution_id)
        state = check_status['QueryExecution']['Status']['State']
        if state in ['RUNNING', 'QUEUED']:
            time.sleep(2)
            
    if state == 'SUCCEEDED':
        print(f"✅ Excellent! The standardized CSV data for AI has safely landed at: {OUTPUT_LOCATION}")
        return {'statusCode': 200, 'body': 'ETL Data Transformation Successful!'}
    else:
        raise Exception(f"❌ Athena ETL pipeline collapsed at error state: {state}")
```
