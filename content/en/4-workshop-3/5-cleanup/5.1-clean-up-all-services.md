Please perform the cleanup in the exact order of the tables below. Absolutely do not delete the S3 Data Lake before deleting other services, as it will cause a system bottleneck error.

#### 1. Delete Machine Learning Layer (Highest priority)

This is the fastest "money burning" component. You must clean it up first.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Delete Campaign | Access **Amazon Personalize** -> Select **Campaigns** -> Click **Delete**. (If you applied the FinOps "Hit and Run" tactic in the previous chapter, skip this step). |
| **2** | Delete Solution | Select the **Solutions** section -> Open your Solution -> Click **Delete**. |
| **3** | Delete Dataset | Open the **Datasets** section -> Sequentially delete all Datasets inside. |
| **4** | Delete Dataset Group | Finally, select **Dataset groups** -> Select the `news_recommender_group` group and click **Delete**. |

> **Note:** The Solution deletion process may take a few minutes. You must wait for the Solution to completely disappear before you can delete the Dataset Group.

---

#### 2. Delete Orchestration and Compute Layer

Remove orchestrators and compute functions to completely stop the system's automatic flow.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Turn off Alarm | Access **Amazon EventBridge** -> Select **Schedules** -> Select the `Trigger-NewsPipeline-Hourly` schedule -> Click **Delete**. |
| **2** | Delete Conductor | Access **AWS Step Functions** -> Select your State Machine -> Click **Delete**. |
| **3** | Delete ETL Function | Access **AWS Lambda** -> Select the `AthenaETLProcessor` function -> Click **Delete**. |

---

#### 3. Delete Data Ingestion & Storage Layer

Clean up Streaming pipelines and physical storage.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Delete Data Catalog | Access **AWS Glue**. Go to **Crawlers** to delete Crawler. Go to **Databases** to delete `clickstream_db` (This action will also delete the tables inside). |
| **2** | Delete Streaming | Access **Kinesis Data Firehose** -> Select the Delivery Stream -> Click **Delete**. |
| **3** | Clean up Data Lake | Access **Amazon S3** -> Select the `clickstream-datalake-v2...` bucket. You **MUST** click the **Empty** button (to clear the Parquet/CSV files inside) first. After successful Emptying, select that bucket again and click **Delete**. |
| **4** | Delete Athena Logs | Still in **Amazon S3**, find the bucket whose name starts with `aws-athena-query-results-...` -> Proceed to **Empty** and **Delete** similarly. |
| **5** | Delete Notification | Access **Amazon SNS** -> Select Topics -> Delete the `Pipeline_Completion_Alert` topic. |

---

#### 4. Security Cleanup (IAM Credentials & Roles)

This is an extremely important step to protect your AWS account from security risks after finishing the practice.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Delete Simulator User | Access **IAM** -> Select **Users** -> Check the `Clickstream-Data-Pusher` User that you created in Chapter 2 -> Click **Delete** to completely delete this sub-account (The accompanying Access Key will also be permanently destroyed with the User). |
| **2** | Clean up IAM Roles | (Optional) Switch to the **Roles** section, find and delete the Roles automatically created by the system (usually containing the phrases *Personalize, Firehose, StepFunctions* or *Glue*). |
