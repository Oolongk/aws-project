Hello, welcome to **Chapter 5: Cleanup and Conclusion**. You have successfully completed building a massive Data Pipeline system and integrated AI on AWS. 

However, in a practice environment (Lab), if we just let the system run continuously, the AWS bill at the end of the month will be a massive number (especially the Amazon Personalize service). Therefore, cleaning up resources is a mandatory discipline for every Cloud/Data engineer.

In this chapter, we will proceed to "tear down" the entire system in a strict reverse order from top to bottom to avoid being stuck with Dependencies errors.
