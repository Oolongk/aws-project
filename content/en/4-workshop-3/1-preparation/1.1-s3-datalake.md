Amazon S3 will act as the central storage repository (Data Lake) containing all raw and transformed data for the system.

#### Initialization steps
1. Access the **Amazon S3** service on the AWS Console and click the **Create bucket** button.
2. In the **Bucket name** field, enter a unique name (for example: `clickstream-datalake-v2-yourname`).
3. In the **AWS Region** field, select `ap-southeast-1` (Singapore) to optimize latency.
4. Keep the other default settings (ensure Block Public Access is turned on for data security) and click **Create bucket**.

#### Set up folder structure (Partitioning)
Access the bucket you just created and create the following 2 folders using the **Create folder** button:
1. `data/` folder: This is where Kinesis Firehose will dump raw data in Parquet format.
2. `personalize_data/` folder: The place containing the CSV file after the ETL process is completed, ready for Artificial Intelligence (AI).
