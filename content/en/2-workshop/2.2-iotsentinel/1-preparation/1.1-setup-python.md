#### Setup Python Environment

To run the truck simulator source code, your computer needs to have Python and the AWS IoT connection library installed.

1. Check the Python version on your computer by opening Terminal/Command Prompt and typing the command:
   `python --version` (Requires version 3.9 or higher).

![Check Python](/aws-project/images/IoTSentinel/1-chuan-bi/python-check.png?featherlight=false&width=90pc)

2. **Install Python (For computers without it):**
   - **For Windows:** Visit the [python.org/downloads](https://www.python.org/downloads/) page, download the latest installer.
     > **Important note:** On the first installation screen, you MUST check the box **"Add Python.exe to PATH"** before clicking Install Now. This helps the Terminal recognize the `python` command.
   - **For macOS (Using Homebrew):**
     ```bash
     brew install python
     ```
   - **For Linux (Ubuntu/Debian):**
     ```bash
     sudo apt update && sudo apt install python3 python3-pip -y
     ```

3. Install the **AWSIoTPythonSDK** library. This is the most important library for performing MQTT communication.
   Run the command:
   
   ```bash
   pip install AWSIoTPythonSDK
   ```

![Install SDK](/aws-project/images/IoTSentinel/1-chuan-bi/install.png?featherlight=false&width=90pc)
