# Social Media Sentiment Sentinel

Welcome to the project for building an automated Serverless YouTube comment sentiment analysis system.

In this series, we will solve a real Big Data problem:
1.  Automatically collect data from YouTube.
2.  Use Generative AI (**Claude 3**) to understand context and sarcasm.
3.  Overcome the Rate Limit constraints of AWS Academy accounts.
4.  Visualize data on QuickSight.
