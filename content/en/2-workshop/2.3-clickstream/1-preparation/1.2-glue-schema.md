In order for Kinesis Firehose to compress data from unstructured JSON to the Apache Parquet highly compressed columnar format directly on the stream, it needs a "blueprint" to know which columns the data contains. We will solve this problem using **AWS Glue Data Catalog** (Including Database and Crawler).

#### Step 1: Create Database

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Access service | In the AWS Console, search for and open **AWS Glue**. |
| **2** | Go to Data Catalog | On the left menu, select **Databases** and click **Add database**. |
| **3** | Declare name | Enter the name `clickstream_db` and click **Create database**. |

#### Step 2: Create structure table with Crawler (Schema-on-Read technique)

To get an accurate table to pass to Firehose, the smartest way is to let a Crawler test read a sample JSON file.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Create dummy file | Create a `sample.json` file on your computer containing: `{"user_id": "1", "event_type": "view", "event_timestamp": "2026", "page_url": "/home", "device_os": "iOS"}`. |
| **2** | Upload to S3 | Upload this file to a temporary folder on S3 (for example: `s3://clickstream-datalake-v2/schema-sample/`). |
| **3** | Create Crawler | Return to AWS Glue, select **Crawlers** -> Click **Create crawler** (Name: `Schema_Crawler`). |
| **4** | Point to data source | Select Add a data source and point the S3 path to the exact folder containing the `sample.json` file above. |
| **5** | Permissions and Output | Grant IAM Role permissions, select the target Database as `clickstream_db` and click **Run Crawler**. |
