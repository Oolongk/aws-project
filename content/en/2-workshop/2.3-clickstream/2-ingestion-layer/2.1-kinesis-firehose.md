Kinesis Data Firehose acts as a streaming data reception station and performs format conversion (JSON to Parquet) directly on the data stream (on-the-fly).

#### Step-by-step deployment guide

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Access AWS Console | Search for **Kinesis** -> select **Data Firehose**. |
| **2** | Create Stream | Click **Create delivery stream**. |
| **3** | Configure Source | Select Source as **Direct PUT**. |
| **4** | Configure Destination | Select Destination as **Amazon S3**. |
| **5** | Enable compression feature | Find the **Transform and convert records** section, select **Enable** in the *Convert record format* box. |
| **6** | Select Format | Select Output format as **Apache Parquet**. |
| **7** | Point to AWS Glue Catalog | In the Schema configuration section, select the correct **Database** (`clickstream_db`) and **Table** that the Crawler just generated in section 1.2. |
| **8** | Configure target S3 | In the Destination settings section, select your S3 Bucket and enter Prefix as `data/`. Click Create. |

> **Important note:** In the **Destination settings** section, make sure you select the correct S3 bucket created in Chapter 1. In the **Prefix** section, enter `data/` so that Firehose automatically gathers data into this folder.

---

#### Check the results
After clicking **Create delivery stream**, please return to the S3 interface. If you see folders automatically created in the format `/year/month/day/hour/`, it means the system is ready to receive data!
