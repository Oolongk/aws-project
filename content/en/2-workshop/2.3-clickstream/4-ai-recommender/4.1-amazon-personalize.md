This article guides you on how to set up the AutoML cycle, create an API gateway to serve prediction results, and implement an optimal FinOps strategy for infrastructure costs.

#### Step 1: Initialize Dataset Group and Import data from S3

We need to load the processed CSV file from the `personalize_data/` folder on S3 into the Machine Learning environment.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Access service | In the AWS Console search bar, type **Personalize** and select this service. |
| **2** | Create Dataset Group | Click the **Create dataset group** button, name it `news_recommender_group`. |
| **3** | Select Domain | Select the Domain type as **Custom** to optimize system customizability. |
| **4** | Define Schema | Declare the mandatory interaction table structure including 3 core fields fully capitalized: `USER_ID` (string), `ITEM_ID` (string), `TIMESTAMP` (long/bigint). |
| **5** | Create Import Job | In the Dataset import job section, name the job and point the S3 URL path accurately to the ETL-processed CSV file in Chapter 3. |
| **6** | Complete | Grant S3 read permissions for Personalize via the automatic IAM Role creation option and click **Start import**. The data loading process takes about 10-15 minutes. |

---

#### Step 2: Train artificial intelligence model (Training Solution)

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Initialize Solution | In the Dataset Group menu, select the **Solutions** section -> Click **Create solution**. |
| **2** | Name the brain | Enter the Solution name as `news_behavior_matrix_model`. |
| **3** | Select Algorithm | In the Solution type section, select the specialized **Recipe**: `aws-user-personalization`. |
| **4** | Configure parameters | Keep all Hyperparameters at AWS AutoML default levels. |
| **5** | Proceed to Train | Click the **Create and train solution** button. AWS will automatically run algorithms to optimize the interaction matrix. This process takes about 40-50 minutes. |

---

#### Step 3: Configure API Endpoint and FinOps "Hit and Run" Discipline

In order to send queries to get recommendation results from the application or source code, we need to provision a Campaign gateway connecting directly to the AI brain.

| Step | Action | Technical details |
| :--- | :--- | :--- |
| **1** | Initialize Campaign | On the left menu, select **Campaigns** -> Click the **Create campaign** button. |
| **2** | Link model | Name the campaign `news_live_inference_api`. Select the Solution version successfully trained in Step 2. |
| **3** | Limit capacity | In the **Minimum provisioned TPS** box, you must enter the number `1` (Set minimum capacity to 1 transaction per second). |
| **4** | Activate Endpoint | Click **Create campaign** and wait for the status to turn green **Active**. |

> **FinOps Crucial Alert:** The Amazon Personalize Campaign connection gateway has a fixed maintenance cost of $0.20 per hour of continuous operation (equivalent to about $146/month) even when no one accesses it. Since this is an R&D Lab environment, you must adhere to the FinOps **"Hit and Run"** discipline: Turn on API gateway -> Perform a quick test to capture evidence of results -> **Click the DELETE button to delete the Campaign immediately**. This action helps you eliminate AWS background billing, protect your wallet, and keep the total cost of this entire AI lab under **$0.50**.
