Initialize a storage table on Amazon DynamoDB to store the Meta metrics of Heroes.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Access DynamoDB | In the AWS Console search bar, type **DynamoDB** > Select **Tables** from the left menu > Click **Create table**. |
| 2 | Configure Table Name | Table name: `dota2_hero_metrics`. |
| 3 | Configure Primary Key | Partition key: Enter `hero_id` and select data type **String (S)**. Sort key: Enter `match_date` and select data type **String (S)**. |
| 4 | Configure Settings | Under *Table settings*, check **Customize settings** to optimize costs. |
| 5 | Optimize Capacity Mode | Under *Read/write capacity mode*, select **On-demand** (Pay-per-request). |
| 6 | Complete | Scroll to the bottom and click the orange **Create table** button. |
