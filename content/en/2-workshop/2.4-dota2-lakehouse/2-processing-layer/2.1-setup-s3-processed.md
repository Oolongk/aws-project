We need to create a new Bucket that acts as the clean data store (Processed Data Lake).

| Step | Action | Technical Details |
|---|---|---|
| 1 | Access the AWS Console | Open the **S3** service > Select **Create bucket**. |
| 2 | Set Bucket name | Enter the name: `dota2-processed-zone-yourname` (Remember to select the same Region as the Raw Bucket). |
| 3 | Default security | Ensure **Block all public access** is enabled. |
| 4 | Complete | Click **Create bucket**. |
