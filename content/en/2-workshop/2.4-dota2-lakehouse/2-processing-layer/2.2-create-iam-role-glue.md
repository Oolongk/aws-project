AWS Glue is a computation service — it does not automatically have permission to access your S3 storage buckets. We must create an "employee badge" (IAM Role) for it with access permissions to both buckets.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Open IAM Console | Access the **IAM** service > Select **Roles** in the left menu > Click **Create role**. |
| 2 | Select Trusted Entity | Select **AWS service** > Find and select **Glue** > Click **Next**. |
| 3 | Attach Policy | Find and check the policies: `AmazonS3FullAccess` (temporarily grant full S3 permissions to Glue for smooth operation) and `AWSGlueServiceRole` > Click **Next**. |
| 4 | Set Role name | Set the name: `Glue_Dota2_Processing_Role`. |
| 5 | Complete | Scroll down and click **Create role**. |
