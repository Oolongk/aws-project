This is the soul of the system. We will create an ETL Job on AWS Glue to read JSON files, flatten the player array, and write output as Parquet.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Open AWS Glue | In the Console, find **AWS Glue** > Select **ETL jobs** (left menu). |
| 2 | Initialize Job | Select the **Script editor** option > Select **Spark** > Click **Create script**. |
| 3 | Configure Job Details | Switch to the **Job details** tab. Set name: `dota2_etl_job`. Under IAM Role, select `Glue_Dota2_Processing_Role` (created in Step 2.2). |
| 4 | Optimize cost | In the *Job bookmark* section, select Enable. In the *Number of workers* section, reduce from 10 to **2** (Since we are using a small dataset, we don't need large machines). |
| 5 | Insert Code | Switch back to the **Script** tab, paste the PySpark code below. Remember to replace the `RAW_PATH` and `PROCESSED_PATH` variables with your Bucket names. |
| 6 | Save and Run | Click **Save** > Click **Run**. Wait about 2-3 minutes, then check the S3 Processed Bucket to see the results. |

**Complete PySpark code:**

```python
import sys
from awsglue.transforms import *
from awsglue.utils import getResolvedOptions
from pyspark.context import SparkContext
from awsglue.context import GlueContext
from awsglue.job import Job
from pyspark.sql.functions import explode, col, from_unixtime, to_date

sc = SparkContext.getOrCreate()
glueContext = GlueContext(sc)
spark = glueContext.spark_session

RAW_PATH = "s3://dota2-raw-zone-yourname/raw_matches/"
PROCESSED_PATH = "s3://dota2-processed-zone-yourname/matches_parquet/"

# 1. Read raw JSON data
print("Starting to read data from S3 Raw...")
df = spark.read.json(RAW_PATH)

# 2. Process data (Flattening)
# Explode the participants array into individual rows
df_exploded = df.select(
    col("match_id"),
    to_date(from_unixtime(col("start_time"))).alias("match_date"),
    explode(col("players")).alias("player")
)

# Extract required fields from the player object
df_final = df_exploded.select(
    "match_id",
    "match_date",
    col("player.account_id").alias("account_id"),
    col("player.hero_id").alias("hero_id"),
    col("player.win").alias("is_win")
)

# 3. Write data in Snappy-compressed Parquet format
print("Starting to write data in Parquet format...")
df_final.write.mode("append") \
    .partitionBy("match_date") \
    .parquet(PROCESSED_PATH, compression="snappy")

print("ETL Job complete!")
```
