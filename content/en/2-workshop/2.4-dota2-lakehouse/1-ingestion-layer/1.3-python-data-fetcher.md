We will write a Python script to act as the Ingestion Bot: call the OpenDota API, retrieve the 100 most recent professional matches, and push the JSON payload up to S3.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Prepare environment | Open Terminal (Command Prompt), install the AWS library: `pip install boto3 requests` |
| 2 | Load IAM keys | Type the command `aws configure`. Paste the Access Key and Secret Key retrieved in section 1.2. Select Region `ap-southeast-1`. |
| 3 | Write source code | Create a file named `dota2_ingestion.py` and paste the code below. (Remember to update the `BUCKET_NAME`). |
| 4 | Run Script | Type `python dota2_ingestion.py` in the Terminal. |
| 5 | Validate | Access the AWS Console > **S3** > Open the Raw Bucket. You will see a new directory structure automatically created containing JSON files. |

Source code `dota2_ingestion.py`:

```python
import requests
import boto3
import json
from datetime import datetime

# API and S3 configuration
API_URL = "https://api.opendota.com/api/proMatches"
BUCKET_NAME = "dota2-raw-zone-yourname" # Replace with your S3 Raw Bucket name
PREFIX = "raw_matches"

def fetch_and_upload():
    print("Calling OpenDota API...")
    response = requests.get(API_URL)
    
    if response.status_code == 200:
        matches = response.json()
        
        # Create path following Apache Hive Partitioning standard (dt=YYYY-MM-DD)
        date_str = datetime.now().strftime("%Y-%m-%d")
        file_name = f"matches_{int(datetime.now().timestamp())}.json"
        s3_key = f"{PREFIX}/dt={date_str}/{file_name}"
        
        # PutObject to Amazon S3
        s3 = boto3.client('s3')
        s3.put_object(
            Bucket=BUCKET_NAME,
            Key=s3_key,
            Body=json.dumps(matches),
            ContentType='application/json'
        )
        print(f"Success! Pushed {len(matches)} matches to S3 at: {s3_key}")
    else:
        print("API error:", response.status_code)

if __name__ == "__main__":
    fetch_and_upload()
```
