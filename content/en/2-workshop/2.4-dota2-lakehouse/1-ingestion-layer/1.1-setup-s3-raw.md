Create an Amazon S3 Bucket that acts as the "Landing Zone" for storing raw JSON data.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Access the AWS Console | Log in and search for the **S3** service. |
| 2 | Initialize Bucket | Click the orange **Create bucket** button. |
| 3 | Configure General | Bucket name: `dota2-raw-zone-yourname` (name must be lowercase, no accents, globally unique). Region: `ap-southeast-1` (Singapore). |
| 4 | Configure Object Ownership | Keep **ACLs disabled (recommended)**. |
| 5 | Configure Block Public Access | Check **Block all public access** for absolute security. |
| 6 | Complete | Scroll to the bottom and click **Create bucket**. |
