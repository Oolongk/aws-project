A mandatory rule of Amazon Athena is: It needs an S3 Bucket as a "buffer zone" to store the results of the SQL statements you type.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Create buffer Bucket | Open **S3 Console**, create a new bucket named: `dota2-athena-results-yourname`. (Remember to block public access). |
| 2 | Open Athena | From the search bar, access the **Athena** service. |
| 3 | Open Settings | Click the **Settings** tab in the top right menu bar. |
| 4 | Configure Location | In the *Query result location* field, click **Manage** and point the path to the newly created bucket: `s3://dota2-athena-results-yourname/`. |
| 5 | Save settings | Click **Save**. Athena is now ready for you to type commands. |
