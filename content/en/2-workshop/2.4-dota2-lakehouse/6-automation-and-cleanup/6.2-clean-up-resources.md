To avoid unexpected charges on your AWS bill at the end of the month, delete all services and resources created during this project.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Delete DynamoDB Table | Open **DynamoDB** > **Tables** > Select the `dota2_hero_metrics` table > Click **Delete** > Type `confirm` to confirm. |
| 2 | Delete API Gateway | Open **API Gateway** > Select `dota2-public-api` > Click **Delete** in the top right > Type `confirm` to confirm. |
| 3 | Delete Lambdas & EventBridge | Go to **Lambda**, delete both functions (`dota2-auto-ingestion` and `dota2-backend-api`). Go to **EventBridge**, delete the created rules. |
| 4 | Delete AWS Glue & Athena | Go to **AWS Glue** and delete the Job `dota2_etl_job`. In **Athena**, open the Query Editor and run `DROP TABLE dota2_matches;`. |
| 5 | Clean Up S3 Buckets | Go to **S3**. For each Bucket (Raw, Processed, Athena Results, Frontend), click **Empty** (type `permanently delete`) first, then click **Delete** (type bucket name). |
| 6 | Delete IAM Roles/Users | Go to **IAM** > Delete User `dota2-ingestion-bot`. Delete Role `Glue_Dota2_Processing_Role`. |
