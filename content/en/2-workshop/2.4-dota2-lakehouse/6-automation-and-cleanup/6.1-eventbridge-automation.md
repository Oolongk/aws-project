We will perform 2 main tasks: Deploy the data ingestion Python script to AWS Lambda, and set up an EventBridge Schedule to run automatically at 2:00 AM daily.

**Part 1: Create Ingestion Lambda (Replacing Local Ingestion Script)**

| Step | Action | Technical Details |
|---|---|---|
| 1 | Create Lambda Function | Open **Lambda** > Click **Create function**. Name: `dota2-auto-ingestion`. Runtime: **Python 3.9**. |
| 2 | Grant S3 Permissions | Similar to section 5.1, go to **Configuration** > **Permissions** > Open the Role and add an Inline Policy allowing `s3:PutObject` on the Raw bucket. |
| 3 | Paste Source Code | Paste the Python code below into the Code Editor. Replace `YOUR_RAW_BUCKET` with your bucket name. Click **Deploy**. |
| 4 | Configure Timeout | Go to **Configuration** > **General configuration** > **Edit**. Increase Timeout from 3 seconds to **1 minute**. Click **Save**. |

**`dota2-auto-ingestion` Source Code (Using default standard library `urllib` instead of `requests` so no Lambda Layer is required):**

```python
import urllib.request
import boto3
import json
from datetime import datetime

API_URL = "https://api.opendota.com/api/proMatches"
BUCKET_NAME = "YOUR_RAW_BUCKET"
PREFIX = "raw_matches"

def lambda_handler(event, context):
    print("Starting data ingestion from OpenDota API...")
    req = urllib.request.Request(API_URL, headers={'User-Agent': 'Mozilla/5.0'})
    
    with urllib.request.urlopen(req) as response:
        if response.status == 200:
            matches = json.loads(response.read().decode())
            date_str = datetime.now().strftime("%Y-%m-%d")
            file_name = f"matches_{int(datetime.now().timestamp())}.json"
            s3_key = f"{PREFIX}/dt={date_str}/{file_name}"
            
            s3 = boto3.client('s3')
            s3.put_object(Bucket=BUCKET_NAME, Key=s3_key, Body=json.dumps(matches), ContentType='application/json')
            
            return {"status": 200, "message": f"Successfully pushed {len(matches)} matches to S3"}
        else:
            return {"status": response.status, "message": "API invocation error"}
```
