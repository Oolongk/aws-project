We will build a Lambda function that acts as the API Backend responsible for receiving the `hero_id` parameter sent from the browser, querying DynamoDB, and returning the JSON result.

| Step | Action | Technical Details |
|---|---|---|
| 1 | Access AWS Console | Search for the **Lambda** service in the search bar. |
| 2 | Initialize Function | Select **Functions** from the left menu > Click the orange **Create function** button. |
| 3 | Basic Configuration | Select *Author from scratch*. Function name: `dota2-backend-api`. Runtime: Select **Python 3.9** (or newer). |
| 4 | Configure Permissions | Expand *Change default execution role* > Select **Create a new role with basic Lambda permissions** (AWS will automatically create a secure basic Role). Click **Create function**. |
| 5 | Attach DynamoDB Read Permissions | Go to the *Configuration* tab > *Permissions* section > Click the blue *Role name* link. The system will open the IAM tab. |
| 6 | Add Inline Policy | Click **Add permissions** > **Create inline policy** > Select the **JSON** tab and paste the code below (Remember to replace `YOUR_ACCOUNT_ID`) > Set policy name: `DynamoDB_Read_Dota2_Metrics` > Click **Create policy**. |
| 7 | Write API Source Code | Return to the Lambda Function tab > Scroll down to the Code editor, clear the default code, paste the Python Backend code below > Click the orange **Deploy** button. |

JSON Policy Code to grant read permissions to Lambda:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "dynamodb:GetItem"
            ],
            "Resource": "arn:aws:dynamodb:ap-southeast-1:YOUR_ACCOUNT_ID:table/dota2_hero_metrics"
        }
    ]
}
```

Python Backend Source Code:
```python
import json
import boto3

DYNAMODB_TABLE = "dota2_hero_metrics"

def lambda_handler(event, context):
    print("Received event:", json.dumps(event))
    
    # 1. Extract hero_id parameter from API Gateway (Query String or Path Parameter)
    query_params = event.get('queryStringParameters') or {}
    hero_id = query_params.get('hero_id')
    
    if not hero_id:
        return {
            'statusCode': 400,
            'headers': {
                'Access-Control-Allow-Origin': '*', # Enable CORS to prevent Browser blocking errors
                'Content-Type': 'application/json'
            },
            'body': json.dumps({'error': 'The hero_id parameter is required!'})
        }
    
    # 2. Query data directly from Amazon DynamoDB using Key Lookups
    dynamodb = boto3.resource('dynamodb', region_name='ap-southeast-1')
    table = dynamodb.Table(DYNAMODB_TABLE)
    
    response = table.get_item(Key={'hero_id': int(hero_id)})
    item = response.get('Item')
    
    if not item:
        return {
            'statusCode': 404,
            'headers': {'Access-Control-Allow-Origin': '*', 'Content-Type': 'application/json'},
            'body': json.dumps({'message': f'No data found for Hero ID {hero_id}'})
        }
        
    # 3. Return clean JSON response to Frontend
    return {
        'statusCode': 200,
        'headers': {
            'Access-Control-Allow-Origin': '*',
            'Content-Type': 'application/json'
        },
        'body': json.dumps(item)
    }
```
