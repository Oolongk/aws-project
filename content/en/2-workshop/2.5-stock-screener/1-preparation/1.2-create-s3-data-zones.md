Create three separate S3 buckets: Raw, Processed, and Static Website. Raw and Processed buckets remain non-public; the Website bucket is publicly exposed via CloudFront/S3 website hosting.

## Create Buckets

| Step | Action | Technical Details |
|---|---|---|
| 1 | Amazon S3 → **Create bucket** | Create Raw Bucket |
| 2 | Enter name | `stock-screener-raw-your-name` |
| 3 | Select Region | `ap-southeast-1` or the Region you use for Glue |
| 4 | Retain Block Public Access | Raw data remains non-public |
| 5 | Repeat | Create `stock-screener-processed-your-name` |
| 6 | Repeat | Create `stock-screener-web-your-name` for frontend |

## Prefix Contract
````text
# Raw
raw_us_market/YYYY/MM/DD/us_prices_raw.parquet
raw_us_market/YYYY/MM/DD/us_company_info.parquet
raw_us_market/YYYY/MM/DD/us_financials_raw.parquet

# Processed
processed_qmj/as_of_date=YYYY-MM-DD/part-*.snappy.parquet

# Static frontend
index.html
assets/
````

> **Architectural Principle – Component Isolation.** The browser never reads from the Raw or Processed Bucket directly. It only downloads static assets from the Web Bucket and retrieves QMJ data via API Gateway.
