Create dedicated IAM Roles for AWS Glue, Lambda Loader, Lambda Reader, and EventBridge Scheduler. Do not hardcode Access Keys in Python scripts.

## Role Matrix

| Role | Used By | Least Privilege |
|---|---|---|
| `AWSGlueServiceRole-StockScreener` | Daily Ingestion and QMJ Transformation | Read/Write Raw, Read/Write Processed |
| `LambdaQMJLoaderRole` | Lambda S3 trigger | List/Get QMJ Parquet, `dynamodb:BatchWriteItem`, CloudWatch Logs |
| `LambdaStockScreenerReaderRole` | Lambda Reader | `dynamodb:Query`, CloudWatch Logs |
| `EventBridgeSchedulerStockScreenerRole` | EventBridge Scheduler | `glue:StartJobRun` for Daily Ingestion Job |

> **Architectural Principle – Strict boundary per IAM role.** QMJ Transform does not require DynamoDB permissions because the source code only writes Processed Parquet. Lambda Loader is the only service with batch write permissions to `qmj_screener`.

# Create Glue Role

| Step | Action | Technical Details |
|---|---|---|
| 1 | IAM → Roles → **Create role** | Select `AWS service` |
| 2 | Select **Glue** | Trust principal is `glue.amazonaws.com` |
| 3 | Set Role name | `AWSGlueServiceRole-StockScreener` |
| 4 | Attach managed policy | `service-role/AWSGlueServiceRole` |
| 5 | Select **Create role** | Create base role |
| 6 | Role → Permissions → **Add permissions** | Select **Create inline policy** |
| 7 | Select tab **JSON** | Paste S3 policy below |
| 8 | Set policy name | `StockScreenerGlueS3Access` |
| 9 | Select **Create policy** | Done |

````json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListDataBuckets",
      "Effect": "Allow",
      "Action": ["s3:ListBucket", "s3:GetBucketLocation"],
      "Resource": [
        "arn:aws:s3:::stock-screener-raw-your-name",
        "arn:aws:s3:::stock-screener-processed-your-name"
      ]
    },
    {
      "Sid": "ReadWriteRawAndProcessedPrefixes",
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": [
        "arn:aws:s3:::stock-screener-raw-your-name/raw_us_market/*",
        "arn:aws:s3:::stock-screener-processed-your-name/processed_qmj/*"
      ]
    }
  ]
}
````

# Create Lambda QMJ Loader Role

| Step | Action | Technical Details |
|---|---|---|
| 1 | IAM → Roles → **Create role** | Select `AWS service` |
| 2 | Select **Lambda** | Trust principal is `lambda.amazonaws.com` |
| 3 | Set Role name | `LambdaQMJLoaderRole` |
| 4 | Attach `AWSLambdaBasicExecutionRole` | Allows Lambda to write logs to CloudWatch |
| 5 | Select **Create role** | Create base role |
| 6 | Permissions → **Add permissions** | Select **Create inline policy** |
| 7 | Select tab **JSON** | Paste S3 + DynamoDB policy below |
| 8 | Replace `ACCOUNT_ID` | Use your AWS Account ID |
| 9 | Set policy name | `QMJLoaderS3DynamoDBWrite` |
| 10 | Select **Create policy** | Done |

````json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListProcessedQMJPrefixForBackfill",
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::stock-screener-processed-your-name",
      "Condition": {
        "StringLike": {
          "s3:prefix": ["processed_qmj/*"]
        }
      }
    },
    {
      "Sid": "ReadProcessedQMJParquet",
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::stock-screener-processed-your-name/processed_qmj/*"
    },
    {
      "Sid": "BatchWriteQMJScores",
      "Effect": "Allow",
      "Action": ["dynamodb:BatchWriteItem"],
      "Resource": "arn:aws:dynamodb:ap-southeast-1:ACCOUNT_ID:table/qmj_screener"
    }
  ]
}
````

# Create Lambda Reader Role

| Step | Action | Technical Details |
|---|---|---|
| 1 | IAM → Roles → **Create role** | Select `AWS service` → `Lambda` |
| 2 | Set Role name | `LambdaStockScreenerReaderRole` |
| 3 | Attach `AWSLambdaBasicExecutionRole` | Grants CloudWatch Logs write access |
| 4 | Select **Create role** | Create base role |
| 5 | Permissions → **Create inline policy** | Paste DynamoDB read policy |
| 6 | Replace `ACCOUNT_ID` | Use your Account ID |
| 7 | Set policy name | `StockScreenerReaderDynamoDBQuery` |
| 8 | Select **Create policy** | Done |

````json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "QueryQMJHistoryByTicker",
      "Effect": "Allow",
      "Action": ["dynamodb:Query"],
      "Resource": "arn:aws:dynamodb:ap-southeast-1:ACCOUNT_ID:table/qmj_screener"
    }
  ]
}
````

# Create EventBridge Scheduler Execution Role

| Step | Action | Technical Details |
|---|---|---|
| 1 | IAM → Roles → **Create role** | Select Custom trust policy if the UI does not list Scheduler as a use case |
| 2 | Trusted service | Use `scheduler.amazonaws.com` |
| 3 | Set Role name | `EventBridgeSchedulerStockScreenerRole` |
| 4 | Permissions → **Create inline policy** | Grant permission to start the Daily Ingestion Job |
| 5 | Set policy name | `SchedulerStartDailyIngestion` |

````json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "StartDailyIngestion",
      "Effect": "Allow",
      "Action": ["glue:StartJobRun"],
      "Resource": "arn:aws:glue:ap-southeast-1:ACCOUNT_ID:job/us-stock-daily-ingestion"
    }
  ]
}
````

````json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {"Service": "scheduler.amazonaws.com"},
      "Action": "sts:AssumeRole"
    }
  ]
}
````
