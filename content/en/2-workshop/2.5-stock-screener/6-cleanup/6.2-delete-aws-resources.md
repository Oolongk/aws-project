Delete resources in reverse-dependency order from public endpoints back to storage.

| Step | Action | Technical Details |
|---|---|---|
| 1 | EventBridge Scheduler | Disable or delete schedules first |
| 2 | API Gateway | Delete HTTP API |
| 3 | Lambda Reader | Delete `stock-screener-reader` sau API Gateway |
| 4 | S3 Trigger | Delete S3 event notifications or delete Lambda Loader to remove triggers |
| 5 | Lambda QMJ Loader | Delete `qmj-s3-to-dynamodb-loader` |
| 6 | DynamoDB | Delete table `qmj_screener` if historical demo data is no longer needed |
| 7 | Glue Jobs | Delete Daily Ingestion and QMJ Transformation jobs |
| 8 | S3 Web Bucket | Empty bucket and then delete |
| 9 | S3 Processed Bucket | Confirm archiving prior to emptying and deleting |
| 10 | S3 Raw Bucket | Confirm archiving prior to emptying and deleting |
| 11 | IAM Inline Policies/Roles | Detach/delete Role if dedicated to the project |
