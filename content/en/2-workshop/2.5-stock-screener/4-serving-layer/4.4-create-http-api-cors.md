HTTP API exposes Lambda Reader as a public endpoint for browser invocation. API Gateway routes requests to Lambda, which queries DynamoDB.

| Step | Action | Technical Details |
|---|---|---|
| 1 | AWS Console → API Gateway → **create API** | select HTTP API |
| 2 | Click Build | Under HTTP API |
| 3 | Integration | Select Lambda function `stock-screener-reader` |
| 4 | API name | `stock-screener-http-api` |
| 5 | create | create default stage `$default` or custom stage |
| 6 | Routes → create | Method `GET`, route `/scores` |
| 7 | Attach integration | Select Lambda reader |
| 8 | CORS | Allowed origins: Web Bucket/CloudFront domain; methods: `GET,OPTIONS` |
| 9 | Copy the Invoke URL | Use as frontend `API_BASE_URL` |
| 10 | Test | `GET /scores?ticker=AAPL` |
