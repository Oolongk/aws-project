EventBridge Scheduler triggers the Glue Python Shell Job daily. Do does not schedule transformation/loader jobs simultaneously as they must wait for upstream completion.

| Step | Action | Technical Details |
|---|---|---|
| 1 | EventBridge → Scheduler → **create schedule** | create recurring schedule |
| 2 | Schedule name | `stock-screener-daily-ingestion` |
| 3 | Schedule pattern | Select a cron-based schedule |
| 4 | Expression | Example: `cron(0 7 ? * TUE-SAT *)` |
| 5 | Timezone | Select `Asia/Ho_Chi_Minh` if supported by the UI |
| 6 | Target | Universal target: AWS SDK → Glue → `StartJobRun` |
| 7 | Input payload | Paste the JSON below |
| 8 | Execution role | `EventBridgeSchedulerStockScreenerRole` |
| 9 | create schedule | Verify schedule Enabled |
````json
{
  "JobName": "us-stock-daily-ingestion"
}
````
