The QMJ Transform is a Spark ETL Job that reads all Raw Parquet files using `recursiveFileLookup` and outputs data partitioned by `as_of_date`.

## Upload Transform Script

| Step | Action | Technical Details |
|---|---|---|
| 1 | Amazon S3 → `stock-screener-raw-your-name/glue-scripts/` | Use the existing script S3 prefix |
| 2 | Select **Upload** | Upload `qmj_transform.py` |
| 3 | Verify S3 URI | `s3://stock-screener-raw-your-name/glue-scripts/qmj_transform.py` |

## Create Spark Job

| Step | Action | Technical Details |
|---|---|---|
| 1 | AWS Glue → ETL jobs → **Create job** | Open the Job creation wizard |
| 2 | Select job type | Select **Spark** |
| 3 | Enter Job name | `us-stock-qmj-transform` |
| 4 | Select IAM Role | `AWSGlueServiceRole-StockScreener` |
| 5 | Select Script path | URI of `qmj_transform.py` |
| 6 | Select Glue runtime | Use the Spark runtime tested with your project |
| 7 | Select capacity | Start small, increase after reviewing duration and memory |
| 8 | Open **Job parameters** | Enter args in the table below |
| 9 | Select **Save** | Save the job |
| 10 | Select **Run** | Test with an `AS_OF_DATE` that has Raw data |

## Job Parameters

| Key | Sample value | Source used |
|---|---|---|
| `--RAW_BUCKET` | `stock-screener-raw-your-name` | Override Raw Bucket |
| `--RAW_PREFIX` | `raw_us_market` | Override Raw prefix |
| `--PROCESSED_BUCKET` | `stock-screener-processed-your-name` | Override Processed Bucket |
| `--PROCESSED_PREFIX` | `processed_qmj` | Override Processed prefix |
| `--AS_OF_DATE` | `2026-07-03` | Cut-off date for info, prices, and financial reports |
| `--LOOKBACK_DAYS` | `800` | Lookback calendar days for price history |
| `--MIN_PRICE_OBSERVATIONS` | `200` | Parsed but not yet used as a filter in the current source |
````text
In the Glue Console, keys must start with two dashes.
Example: --AS_OF_DATE
````
