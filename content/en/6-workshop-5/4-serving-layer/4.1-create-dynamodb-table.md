Lambda QMJ Loader writes one record per `ticker` for each `as_of_date`. Lambda Reader queries historical data by ticker using the Partition Key.

| Step | Action | Technical Details |
|---|---|---|
| 1 | AWS Console → DynamoDB → **Tables** | Click **create table** |
| 2 | Table name | Enter `qmj_screener` to match the default `TABLE_NAME` in Lambda Loader |
| 3 | Partition key | Enter `ticker` with type `String` |
| 4 | Sort key | Check Add sort key, enter `snapshot_date`, type `String` |
| 5 | Table settings | Select On-demand for demo/portfolio when traffic is uncertain |
| 6 | Click **create table** | Wait for Table status to become `Active` |

{
  "ticker": "AAPL",
  "snapshot_date": "2026-07-06",
  "as_of_date": "2026-07-06",
